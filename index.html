03Projects & Labs
DR Site Connectivity — Fibre P2P Link & Core Switch Upgrade
Enterprise IT · English Press Limited
Problem

The disaster-recovery site had no dedicated link back to the main office, and the aging core switch (Cisco 2960) was limiting network performance and reliability.

What I Did

Contributed as part of a 3-person project team (IT Manager + outsourced consultant). Configured a MikroTik router for a fibre point-to-point link, later extending it into a full routing setup with DHCP and internet access for the DR site.

Tools
Cisco 1300 SeriesMikroTik RouterOSDHCPFibre P2P
Outcome

DR site gained a stable, dedicated connection independent of the primary internet link — directly improving business continuity readiness.

Enterprise IT · English Press Limited

Telephony was managed through the network router rather than a dedicated system — limiting scalability and centralized call management.

What I Did

Tools
